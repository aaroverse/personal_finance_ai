# 账本页面设计

## 批量预处理与例外审核

意图：Aaron 先检查整批建议，只展开例外；焦点从重复表单改成「选择范围、所选个人金额、确认整批」。领域是商户记忆、卡片、匹配、例外、个人归属与凭证。继续用纸白、票据灰、墨字、银行绿及审核琥珀，不加新面板配色。Avenir Next/PingFang SC，14px 行文、12px 理由、手机表单16px；4px 基准、44px 标签点击区、轻边框与原生 details/dialog，保留明确焦点。

操作区用于多选、批改分类／归属；明细按卡片分组，每页50笔，已建议的表单默认收起，例外需主动选择。每行显示来源理由而非伪精确 AI 分数。拒绝自动保存、默认选中未知分类及一次渲染几百个展开表单。确认摘要明确区分匹配／补录、个人／非个人，说明选择可跨分页和筛选。卡片默认归属通过明确保存按钮落盘，只作用未确认明细。

## 2026-10-24：统一上传入口

意图：Aaron 平时看个人流水，需要时上传一份账单，由文件内容决定银行；像拿起一张凭证核对，而不是进入银行专属页面。领域：账本、凭证、银行、卡片、结算、个人归属。色彩沿用纸白 paper #ffffff、票据浅灰 canvas #f7f8fa、墨色 ink #202725、muted #606b66、银行绿 ledger #24634d、轻边界 line #e8ece9。Avenir Next/PingFang SC 不变，14px 交易／12px 元数据／16px 手机表单，4px 基准，44px 点击区。

比较：A「账本 → 各银行独立 section」让银行组织方式压过用户任务；B「账本工具栏上传 → 按内容识别 → 核对凭证」只保留一个动作，采用 B。全部左对齐，金额右对齐，按卡分组是识别结果而非入口；原生 dialog 用同一纸色与轻边框，无新色板、阴影卡墙或装饰。修正最初可能的“每银行一张卡”默认方案：银行尚未识别前不显示银行标题，能力范围仅作次要说明。

```text
我的账本                     上传账单  刷新  退出
个人金额与流水

上传账单                                   关闭
PDF 文件 + 识别并预览
（识别后）已识别银行 / 账单日期 / 卡片及明细
```

上传与识别是焦点；核对时交易与归属为焦点。关闭保留临时选择，清除才清空；不支持的格式给明确反馈，不猜测或套用 UOB。保留键盘焦点、Escape 与确认安全边界。

## 确认与个人支出归属

意图：Aaron 对照卡账单逐笔决定关联／补录，轻松排除妈咪消费；确认前看清金额、卡片和归属。焦点为每笔操作与最终确认摘要，不再增加统计卡片。沿用纸白、票据浅灰、墨字、银行绿及审核琥珀的既有令牌；原生 dialog、select 与 checkbox 配合 44px 标签点击区，不新增层叠阴影。Avenir Next/PingFang SC、14px 行文、12px 元数据和移动表单16px保持一致，4px 间距基准、12/16px 控件分组。领域为消费、卡片、结算、归属、凭证和审核；特征是勾选归属与银行卡事实分离。拒绝默认自动匹配、隐藏归属和批量静默入账。成功与非个人状态用文字常显，未确认表单选择跨逐笔保存保留。

## Statement 预览增量

意图：Aaron 用手机或 MBP 对照银行凭证，先看解析是否可靠，再考虑关联。焦点是按卡分组的交易、两个日期及右对齐 SGD 金额。沿用纸白、浅灰、墨色、银行绿、审核琥珀，不新增品牌配色、侧栏或指标卡。既有 Avenir Next / PingFang SC、14px 交易、12px 元数据、16px 手机输入、4px 间距基准和 44px 控件保持不变。层次用留白及轻分隔，不加阴影。

领域：卡片、结算、凭证、还款、贷记、候选。特征是「用户消费描述与银行商户名并存」，按具体卡片分组、尾四位标识、消费／入账双日期、逐卡余额等式、候选理由和未写入状态。拒绝自动勾选匹配、消费与还款同计、宽表格横滚；使用折叠区、原生上传表单及单列明细。上传状态、错误及清空操作与文件输入相邻，结果不抢占账本首屏。

## 2026-10-22 精简版

用户要求：更干净、简洁。现有页面的问题是标题宣传语、英文眉题、多个解释段和外框占据首屏，让真实交易出现得太晚。

意图：Aaron 打开后迅速查看两种币种支出并找到交易。焦点：金额和记录，不使用营销标题。
领域：消费、币种、卡账户、原始描述、审核。特征：SGD / MYR 成对排版，流水维持姓名／账户／金额的清楚对应。
色彩世界：白纸、浅灰票据、深色字迹、绿色已确认状态、琥珀待审核。
色板：paper #ffffff、canvas #f7f8fa、ink #202725、muted #606b66、ledger #24634d、line #e8ece9。
字体：沿用 Avenir Next / PingFang SC；28px 页面标题、34px 金额、14px 列表、12px 元数据。等宽数字便于逐行核对。
深度：仅用边界和微弱底色分区；移除嵌套卡片。4px 间距基准，24px 区域内边距、44px 操作高度。
筛选：月份和搜索直接可见，账户／币种／分类收进原生 details；已选择数量常显，防止隐藏筛选让结果难以理解。
移动端：交易列表保持主次，分类统计移到下方；避免表格横向滚动。

布局比较：原版“宣传区 → 大筛选卡 → 大汇总 → 交易卡”改为“短标题 → 双币种汇总 → 紧凑工具栏 → 交易”。全部左对齐，金额右对齐。

已确认 / 待确认

自审：不增加侧栏、指标卡或新装饰；去掉所有装饰性英文眉题和页脚标语。沿用原生控件和现有安全渲染逻辑。此轮仅视觉与筛选披露方式变化，不更改账本数据。
